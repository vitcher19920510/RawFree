```

**Новый (с показом выгоды):**
```
premium_7:   399₽ / 7 дней           — базовый
premium_30:  1 368₽ / 30 дней        — выгода 20% (vs 4 недели по 399₽ = 1 710₽)

- 7 дней = 399₽

### 5. СЕРВЕРНАЯ ВАЛИДАЦИЯ RUSTORE (TODO → реализовать)
**Где:** `backend/src/subscriptions/subscriptions.service.ts` — метод `verifyPurchase()`

**Что:** Вместо простого сохранения purchase token — реальный запрос к RuStore API v4 для валидации чека.

**Стандартный flow RuStore:**
1. Клиент получает `purchaseToken` от RuStore Pay SDK
2. Отправляет на бэкенд: `POST /subscription/verify { platform: 'RUSTORE', purchaseToken }`
3. Бэкенд делает POST к `https://api.rustore.ru/pub/applications/{appId}/purchases/{purchaseToken}?token={developerToken}`
4. Проверяет response: `purchaseState: 0` (purchased), `consumed: false`
5. Активирует подписку
